# Adopters

The LF Edge FIDO Device Onboard (FDO) project is an open source
initiative providing implementations, libraries, and tools for secure
and automated device onboarding based on the FIDO Device Onboard
specification.

## What is an adopter?

An **adopter** is an organization, project, or individual that actively
uses one or more components developed by the LF Edge FDO community for a
concrete technical purpose.

**Adoption is not limited to commercial products or production
deployments.**

Testing, interoperability validation, and technical evaluation are
recognized forms of adoption when they involve active use of the
project's software.

Examples include production deployments, product and platform
integration, testing and interoperability, development and evaluation,
research and experimentation, and infrastructure automation.

## How to become an adopter

If your organization or project uses software developed by the LF Edge
FDO community, we encourage you to add yourself to this list.

1.  Open a pull request updating this file.
2.  Add your organization or project to the adopters table.
3.  Provide a brief description of how you use the FDO software.
4.  Indicate your current adoption stage.
5.  Include the year your organization or project started using FDO.
6.  Optionally, provide a public contact who can be reached for
    questions about your adoption.

### Adoption stages

- **Evaluation:** Actively evaluating FDO software through technical
  assessments or proof-of-concept implementations.
- **Development / Testing:** Using FDO components for development,
  integration, validation, or interoperability testing.
- **Production:** Using FDO software in operational environments or
  deployed products.

### Table fields

- **Organization / Project:** The organization, open source project,
  research group, or other adopter.
- **Use Case:** A short description of how FDO software is being used.
- **Adoption Stage:** The current stage of adoption as defined above.
- **Since:** The year the adopter started using FDO, not the year the
  entry was added.
- **Contact:** An optional public contact, such as a GitHub username.
- **Website:** A public website for the organization or project.

## Join the community

We welcome feedback from all adopters, regardless of their adoption
stage.

If you are using LF Edge FDO software, consider sharing your experience,
reporting issues, proposing improvements, or participating in community
discussions.

For more information, visit the [LF Edge FIDO Device Onboard
project](https://lfedge.org/projects/fido-device-onboard/) or the [FIDO
Device Onboard GitHub
organization](https://github.com/fido-device-onboard).
